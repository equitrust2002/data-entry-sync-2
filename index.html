Easy setup – 7 short steps (about 5 minutes, one time only)
Emails are sent by your own Google account through a small script in your Google Sheet. Google asks you once to allow it – that is the “email permission”. Follow the steps in order; press Check Setup at the end and it will tell you exactly which step to fix.
1
Copy the script

Press the amber button. It must say “Script copied”. If your browser blocks copying, press Download Code.gs, open the file in Notepad, Ctrl+A, Ctrl+C.

2
Open Apps Script from your Google Sheet

Open your Google Sheet (button below) → top menu Extensions → Apps Script. A new tab opens with a code editor.

Use the same Google account that owns the sheet. If you are signed into several accounts, use a private/incognito window to avoid mix-ups.

3
Paste and Save

Click inside the code editor → Ctrl+A (select all) → Delete → Ctrl+V (paste) → press the 💾 Save icon (or Ctrl+S).

4
Give the email permission (one time) ← the “no email permission” fix
  1. In the top bar, click the function drop-down (it may say doGet) and choose authorizeEmail.
  2. Press ▶ Run.
  3. A box “Authorization required” appears → Review permissions.
  4. Pick your Google account.
  5. If you see “Google hasn’t verified this app”: click Advanced (small text, bottom-left) → Go to … (unsafe). This is your own script, it is safe.
  6. Click Allow.
  7. At the bottom the log should say Execution completed and a mail “Ullswater Fleet Hub – email permission OK” arrives in your own inbox. That proves the permission works.
5
Deploy it as a Web app

First time: Deploy → New deployment → click the ⚙ gear → Web app → Execute as: Me → Who has access: Anyone → Deploy → copy the Web app URL (ends with /exec).

Already deployed before? Deploy → Manage deployments → ✏ pencil → Version: New version → Deploy. (Skipping “New version” is the #1 reason emails keep failing – the old version has no permission.)

6
Paste the URL and token here

Saved automatically. The token must equal EMAIL_TOKEN at the top of the script (already the same by default).

7
Check and test

Type your email in “Send to” below, then press Test Email Setup. All 5 lines must show ✓ and a test email arrives within a minute.

Still says “no email permission”? Try these in order
  1. Run authorizeEmail again (step 4). If a popup never appeared, allow popups for script.google.com. You must receive the test email in your inbox.
  2. After allowing, you must do Deploy → Manage deployments → ✏ → New version → Deploy (step 5). The old version keeps the old (missing) permission.
  3. Make sure the account you allowed is the one that owns the Sheet and that Execute as is Me.
  4. In Apps Script click ⚙ Project Settings. If “Show appsscript.json manifest file” is ticked, open appsscript.json and delete any oauthScopes line, then Save and redeploy a New version.
  5. Reset: open myaccount.google.com/permissions, remove your Apps Script project, then repeat steps 4 and 5.
  6. No “Advanced” link at all? Your company Google Workspace blocks it – ask your admin, or copy the sheet into a free personal Gmail account and use that.
  7. Need to send right now? Use the Send with my mail app button that appears after a failed send – it needs no permission.
